---

Die API-Referenz ist nach den Diensten der Plattform gegliedert. Einige Detailseiten sind bereits auf Deutsch verfügbar, die übrigen derzeit auf Englisch. Prüfen Sie Verfügbarkeit und erforderliche Berechtigungen für Ihren verwalteten Novaplan-Workspace. Für Integrationszugang wenden Sie sich an [Novaplan Support](/de/contact-us).

| Bereich | Inhalt |
| --- | --- |
| [Authentifizierung](/de/system-overview/authentication) | Anmeldung, Sitzungen, Token, OAuth und SSO. |
| [Konfigurationsverwaltung](/system-overview/configuration-manager) | Konfiguration von Speicher, Modellen und Integrationen. Administrative Änderungen werden von Novaplan abgestimmt. |
| [Konnektorverwaltung](/de/system-overview/connector-manager) | Konnektor-Instanzen, OAuth-Verbindungen und Zugangsdaten. |
| [Crawling-Verwaltung](/de/system-overview/crawling-manager) | Synchronisationsaufträge, Zeitpläne und Status. |
| [Enterprise Search](/system-overview/enterprise-search) | Suche, Chat, Agenten und Quellenangaben. |
| [Wissensdatenbank](/system-overview/knowledge-base) | Inhalte, Ordner, Dateien und Indexierung. |
| [E-Mail-Dienst](/de/system-overview/mail-service) | Vorlagen und Versand systemseitiger Nachrichten. |
| [Speicherdienst](/system-overview/storage) | Dateiablage, Metadaten, Versionierung und Abruf. |
| [Benutzerverwaltung](/system-overview/user-management) | Konten, Organisationen, Gruppen, Teams und Berechtigungen. |

Die Plattform kann intern weitere Endpunkte verwenden. Verwenden Sie für eigene Anwendungen nur die von Novaplan freigegebenen Schnittstellen und authentifizieren Sie Anfragen mit den passenden Benutzer- oder Anwendungsrechten. Die allgemeinen Abläufe sind im [Systemüberblick](/de/system-overview) dargestellt.
