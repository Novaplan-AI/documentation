## Überblick

Das Zoom-Toolset erlaubt Agenten Live-Aktionen mit Meetings, Kontakten, Transkripten und Zoom Docs. Eine Workspace-Administration konfiguriert eine Zoom-App unter **Workspace Settings → Actions**. Nutzende verbinden danach ihre eigenen Konten unter **Your actions**. Für die Suche in synchronisierten Meeting-Inhalten verwenden Sie den [Zoom-Konnektor](/de/connectors/zoom/zoom).

| Bereich | Verfügbare Tools |
| --- | --- |
| Meetings | `list_meetings`, `list_upcoming_meetings`, `list_recurring_meetings_ending_in_range`, `get_meeting`, `create_meeting`, `update_meeting`, `delete_meeting`, `get_meeting_invitation` |
| Transkripte | `get_meeting_transcript` |
| Kontakte und Profil | `list_contacts`, `get_contact`, `get_my_profile` |
| Zoom Docs | `list_folder_children` |

<Warning>
  Das Toolset kann Meetings erstellen, verschieben oder löschen. Prüfen Sie bei wiederkehrenden Meetings, ob die Änderung eine einzelne Instanz oder die ganze Serie betrifft. Meeting-Transkripte können vertrauliche Inhalte enthalten.
</Warning>

## Zoom-App und gemeinsame Instanz einrichten

1. Öffnen Sie den [Zoom App Marketplace](https://marketplace.zoom.us/) und wählen Sie **Develop → Build App → General App**.
2. Wählen Sie **User-managed** und lassen Sie die App privat. Die Wahl zwischen einer benutzerverwalteten und einer Account-Level-App ist nach dem Erstellen nicht änderbar; für die persönliche Anmeldung ist die benutzerverwaltete Variante vorgesehen.
3. Öffnen Sie in Novaplan AI **Workspace Settings → Actions → Zoom → + Setup** oder **Configure** und kopieren Sie die **Redirect URI**.
4. Hinterlegen Sie diese URI in Zoom unter **Basic Information → OAuth Information** sowohl als **OAuth Redirect URL** als auch in der **OAuth Allow List**. Die URL muss exakt übereinstimmen.
5. Fügen Sie unter **Scopes** die für Ihre freigegebenen Funktionen benötigten granularen Zoom-Rechte hinzu. Die vollständige Liste aus der Integrationsanleitung steht unten. Stimmen Sie insbesondere Lösch- und Transkriptzugriffe mit Ihrer Zoom-Administration ab.
6. Kopieren Sie unter **Basic Information → App Credentials** die **Client ID** und das **Client Secret**. Hinterlegen Sie beide in der Zoom-Aktion von Novaplan AI und speichern Sie die Instanz.

Wenn Sie die Scopes später ändern, müssen bereits angemeldete Personen die App erneut autorisieren.

Für das Erstellen einer Zoom-App benötigen Sie in Zoom die **Developer-Rolle**. Wenn **Develop** nicht angezeigt wird, bitten Sie die Zoom-Administration um diese Rolle. Die Redirect URL muss einschließlich Protokoll, Host und Pfad exakt übereinstimmen; für produktive Verbindungen ist HTTPS vorgesehen.

### Berechtigungen nach Funktion

| Funktion | Granulare Zoom-Scopes |
| --- | --- |
| Meetingdetails lesen und Meetings auflisten | `meeting:read:meeting`, `meeting:read:list_meetings`, `meeting:read:list_upcoming_meetings` |
| Vergangene Instanzen und Einladungen lesen | `meeting:read:list_past_instances`, `meeting:read:invitation` |
| Meetings erstellen, ändern und löschen | `meeting:write:meeting`, `meeting:update:meeting`, `meeting:delete:meeting` |
| Eigenes Profil und E-Mail lesen | `user:read:user`, `user:read:email` |
| Aufzeichnungsdaten und Transkripte lesen | `cloud_recording:read:recording`, `cloud_recording:read:meeting_transcript` |
| Kontakte auflisten | `contact:read:list_contacts` |
| Zoom Docs durchsuchen | `docs:read:list_children` |

Zooms ältere allgemeine Scopes wie `meeting:read` sind nicht dieselben wie die hier aufgelisteten granularen Scopes. Prüfen Sie in Zoom, welche Rechte für die geplanten Aktionen und Ihre App tatsächlich verfügbar sind.

## Persönlich verbinden und verwenden

1. Öffnen Sie **Your actions → Zoom** und wählen Sie **Authenticate with OAuth**.
2. Prüfen Sie im Zoom-Fenster die Berechtigungen und wählen Sie **Allow**.
3. Nach erfolgreicher Anmeldung zeigt die Zoom-Aktion den Status **Authenticated**. Öffnen Sie die Startseite und erstellen Sie unter **Agents → +** einen Agenten. Ziehen Sie das Zoom-Toolset auf die Arbeitsfläche und verbinden Sie es mit **Agent Core**, Modell sowie Chat-Ein- und -Ausgabe.

Geben Sie beim Planen Zeitzone, Datum, Dauer und Teilnehmende an. Für Transkripte muss das Meeting aufgezeichnet worden sein und die angemeldete Person Zugriff haben. Bei Anmeldeproblemen prüfen Sie Redirect URL, Allow List, Scopes und persönliche Freigabe. [Novaplan Support](/de/contact-us) hilft bei weiteren Fragen.

## Häufige Fragen

**Was unterscheidet den Zoom-Konnektor vom Zoom-Toolset?** Der [Konnektor](/de/connectors/zoom/zoom) synchronisiert Meetings, Aufzeichnungen und Transkripte in Novaplan AI, damit sie später gesucht werden können. Das Toolset greift bei einer Agentenaktion direkt auf Zoom zu und kann je nach Berechtigung Meetings erstellen, ändern oder löschen. Für die Suche nach älteren organisationsweiten Transkripten verwenden Sie den Konnektor; für das Planen eines Meetings das Toolset.

**Muss die App im Zoom Marketplace veröffentlicht werden?** Nein. Für eine interne Integration bleibt die App privat. Eine Freigabe für Personen in anderen Zoom-Accounts erfordert gegebenenfalls Zooms gesondertes Verfahren für eine veröffentlichbare URL.

**Kann ein Agent nur einen Termin einer wiederkehrenden Serie verschieben?** Ja, sofern die Zoom-Aktion entsprechend berechtigt ist. Nennen Sie die konkrete Instanz und sagen Sie ausdrücklich, dass der Rest der Serie unverändert bleiben soll. Prüfen Sie das Ergebnis vor weiteren Änderungen.

**Wie erhalte ich ein Transkript?** Bitten Sie den Agenten um das Transkript eines aufgezeichneten Meetings. Das Tool liefert lesbare Abschnitte mit Zeitstempeln, sofern Ihr Zoom-Konto Zugriff auf die Aufzeichnung und das Transkript hat.
