<Note>
  Google Docs ist derzeit kein eigenständiger Konnektor. In Drive gespeicherte Google-Dokumente werden über den [Google Drive Konnektor (Englisch)](/connectors/google-workspace/drive/drive) synchronisiert. Wenn Sie nur Dokumente importieren möchten, verwenden Sie dort den Filter **File Extensions**.
</Note>

## Google-Dokumente synchronisieren

Novaplan übernimmt den Großteil der Einrichtung. Wenn Sie die Auswahl nachvollziehen oder selbst anpassen möchten:

1. Richten Sie den [Google Drive Konnektor (Englisch)](/connectors/google-workspace/drive/drive) für Ihre Organisation oder Ihr persönliches Konto ein.
2. Öffnen Sie nach der Authentifizierung der Drive-Instanz **Configure Records**.
3. Fügen Sie unter **Sync Filters** den Filter **File Extensions** hinzu.

<img src="/images/connectors/googleWorkspace/common/sheet1.png" alt="Filter File Extensions für Google Drive hinzufügen" />

4. Wählen Sie als Operator **In**.
5. Wählen Sie die Dokumenttypen `Google Docs`, `docx` und `doc`.

<img src="/images/connectors/googleWorkspace/common/docs2.png" alt="Dokumenttypen im Dateiendungsfilter auswählen" />

Der Operator **In** synchronisiert nur die ausgewählten Typen. Ohne **File Extensions** Filter synchronisiert Drive alle unterstützten Dateitypen, einschließlich Dokumenten.

| Dokumenttyp | Filterwert |
| --- | --- |
| Google Docs | `Google Docs` |
| Microsoft Word | `docx`, `doc` |

Authentifizierung und weitere Einstellungen beschreibt die [Google Drive Anleitung (Englisch)](/connectors/google-workspace/drive/drive#connector-settings).
