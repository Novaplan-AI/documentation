<Note>
  Google Docs ist derzeit kein eigenständiger Konnektor. In Drive gespeicherte Google-Dokumente werden über den [Google Drive Konnektor](/de/connectors/google-workspace/drive/drive) synchronisiert. Wenn Sie nur Dokumente importieren möchten, verwenden Sie dort den Filter **Sync Files with Extensions**.
</Note>

## Google-Dokumente synchronisieren

Novaplan übernimmt den Großteil der Einrichtung. Wenn Sie die Auswahl nachvollziehen oder selbst anpassen möchten:

1. Richten Sie den [Google Drive Konnektor](/de/connectors/google-workspace/drive/drive) für Ihre Organisation oder Ihr persönliches Konto ein.
2. Öffnen Sie nach der Authentifizierung der Drive-Instanz **Configure Records**.
3. Fügen Sie unter **Sync Filters** den Filter **Sync Files with Extensions** hinzu.

<img src="/images/connectors/googleWorkspace/common/sheet1.png" alt="Filter Sync Files with Extensions für Google Drive hinzufügen" />

4. Wählen Sie als Operator **In**.
5. Wählen Sie die Dokumenttypen `Google Docs`, `docx` und `doc`.

<img src="/images/connectors/googleWorkspace/common/docs2.png" alt="Dokumenttypen im Dateiendungsfilter auswählen" />

Der Filter **Sync Files with Extensions** gleicht native Google Docs über ihren Google-Dateityp und Word-Dateien über die Endung ab. **In** synchronisiert nur die ausgewählten Typen. Ohne diesen Filter synchronisiert Drive alle unterstützten Dateitypen, einschließlich Dokumenten.

| Dokumenttyp | Filterwert |
| --- | --- |
| Google Docs | `Google Docs` |
| Microsoft Word | `docx`, `doc` |

Authentifizierung und weitere Einstellungen beschreibt die [Google Drive Anleitung](/de/connectors/google-workspace/drive/drive#konnektoreinstellungen).
