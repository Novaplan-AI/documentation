# Gemini Sprache-zu-Text konfigurieren

![Konfigurationsansicht für Gemini Transkription](/images/ai-models/stt/Gemini_STTConfig.png)

Novaplan AI kann Spracheingaben für Agents und Workflows über Gemini-Modelle transkribieren. Audiodaten werden dabei zur Verarbeitung an die Google-API gesendet. Novaplan unterstützt Sie bei der Einrichtung.

## Erforderliche Angaben

**API Key:** Erstellen Sie in [Google AI Studio](https://aistudio.google.com/app/apikey) über **Create API key** einen Schlüssel für ein Google-Cloud-Projekt. Kopieren Sie ihn und bewahren Sie ihn geschützt auf.

**Model Name:** Geben Sie eine genaue, für Ihr Konto verfügbare Modell-ID ein. Beispiele sind `gemini-2.5-flash`, `gemini-2.5-pro` und `gemini-3-flash-preview`. Prüfen Sie die [aktuelle Gemini-Dokumentation](https://ai.google.dev/docs), denn Preview-Modelle und Audiofunktionen können sich ändern.

Ein **Model Friendly Name** ist optional und erleichtert die Unterscheidung mehrerer Konfigurationen.

1. Klicken Sie im Tab **STT** auf der Gemini-Anbieterkarte auf **Configure**.
2. Geben Sie **API Key** und **Model Name** ein und ergänzen Sie bei Bedarf einen Anzeigenamen.
3. Klicken Sie auf **Add Model**.

API Key und Model Name sind erforderlich. Nutzung zählt zu Kontingent und gegebenenfalls zur Abrechnung Ihres Google-Kontos. Bei Fehlern prüfen Sie Schlüssel, genaue Modell-ID, Audiozugang und API-Quota. [Novaplan Support](/de/contact-us) hilft bei der Einrichtung.
