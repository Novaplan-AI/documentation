# OpenRouter Sprache-zu-Text konfigurieren

OpenRouter kann Transkriptionsmodelle verschiedener Anbieter über einen gemeinsamen API-Schlüssel bereitstellen. Novaplan unterstützt Sie bei der Einrichtung.

**API Key:** Erstellen Sie unter **Keys** in Ihrem [OpenRouter-Konto](https://openrouter.ai/) einen Schlüssel. Er beginnt üblicherweise mit `sk-or-`. Bewahren Sie ihn geschützt auf.

**Model Name:** Geben Sie die genaue ID eines verfügbaren Transkriptionsmodells im Format `anbieter/modell` ein, beispielsweise `openai/whisper-1`. Prüfen Sie den [aktuellen OpenRouter-Modellkatalog](https://openrouter.ai/models).

Ein **Model Friendly Name** ist optional. Für die Textgenerierung gibt es eine separate [OpenRouter-Anleitung](/de/ai-models/llm/openrouter). [Novaplan Support](/de/contact-us) hilft bei der Einrichtung.
