# OpenAI Sprache-zu-Text konfigurieren

![Konfigurationsansicht für OpenAI Transkription](/images/ai-models/stt/OpenAI_STTConfig.png)

Novaplan AI kann Spracheingaben für Agents und Workflows über OpenAI-Modelle transkribieren. Dabei werden Audiodaten zur Verarbeitung an die OpenAI-API gesendet. Novaplan unterstützt Sie bei der Einrichtung.

## Erforderliche Angaben

**API Key:** Erstellen Sie in Ihrem [OpenAI-Konto](https://platform.openai.com/api-keys) unter **API Keys** einen geheimen Schlüssel, kopieren Sie ihn sofort und bewahren Sie ihn geschützt auf.

**Model Name:** Geben Sie die genaue ID eines verfügbaren Transkriptionsmodells ein. Beispiele sind `whisper-1`, `gpt-4o-transcribe` und `gpt-4o-mini-transcribe`. Prüfen Sie die [aktuelle OpenAI-Dokumentation zu Sprache-zu-Text](https://platform.openai.com/docs/guides/speech-to-text), Sprachen, Funktionen und den Zugang Ihres Kontos.

Ein **Model Friendly Name** ist optional und erleichtert die Unterscheidung mehrerer Konfigurationen.

1. Klicken Sie im Tab **STT** auf der OpenAI-Anbieterkarte auf **Configure**.
2. Tragen Sie **API Key** und **Model Name** ein und ergänzen Sie bei Bedarf einen Anzeigenamen.
3. Klicken Sie auf **Add Model**.

API Key und Model Name sind erforderlich. Transkriptionsaufrufe zählen zu Kontingent und Abrechnung Ihres OpenAI-Kontos; Modelle können unterschiedlich abgerechnet werden. Bei Fehlern prüfen Sie Schlüssel, genaue Modell-ID, Zugang zur Transkriptions-API und Abrechnung. [Novaplan Support](/de/contact-us) hilft bei der Einrichtung.
