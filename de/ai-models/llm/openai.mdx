# OpenAI konfigurieren

![Konfigurationsansicht für OpenAI](/images/ai-models/llm/OpenAI_LLMConfig.png)

Novaplan AI kann OpenAI-Sprachmodelle für KI-Funktionen in Ihrem Workspace verwenden. Novaplan unterstützt Sie bei der Einrichtung. Für die Verbindung benötigen Sie einen gültigen API-Schlüssel und den Namen eines Modells, auf das Ihr OpenAI-Konto zugreifen darf.

## Erforderliche Angaben

### API Key

Melden Sie sich bei Ihrem [OpenAI-Konto](https://platform.openai.com/account/api-keys) an, öffnen Sie den Bereich für API-Schlüssel und erstellen Sie einen neuen geheimen Schlüssel. Kopieren Sie ihn sofort; er wird nur bei der Erstellung vollständig angezeigt. Geben Sie ihn nicht öffentlich weiter. Die Verwendung der OpenAI-API wird Ihrem OpenAI-Konto und dessen Abrechnung zugeordnet.

### Model Name

Der **Model Name** bezeichnet das konkrete Modell, das Novaplan AI ansprechen soll. Beispiele sind `gpt-5`, `gpt-5-mini` und `gpt-5-nano`. Prüfen Sie die [aktuelle Modellübersicht von OpenAI](https://platform.openai.com/docs/models) sowie die Verfügbarkeit für Ihr Konto, bevor Sie eine Modell-ID übernehmen. Modelle unterscheiden sich in Fähigkeiten, Antwortzeit und Kosten.

## Modell hinzufügen

1. Klicken Sie auf der OpenAI-Anbieterkarte auf **Configure**.
2. Tragen Sie den **API Key** ein.
3. Geben Sie unter **Model Name** die passende Modell-ID ein.
4. Klicken Sie auf **Add Model**, um die Angaben zu speichern und prüfen zu lassen.

Beide Felder sind erforderlich. Bei einem Authentifizierungsfehler prüfen Sie den Schlüssel, die Berechtigung Ihres Kontos und gegebenenfalls dessen Abrechnung. Wird ein Modell nicht gefunden, kontrollieren Sie die genaue Schreibweise und den Zugang Ihres Kontos zu diesem Modell. [Novaplan Support](/de/contact-us) hilft bei der Einrichtung.
