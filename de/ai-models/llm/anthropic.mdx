# Anthropic konfigurieren

![Konfigurationsansicht für Anthropic](/images/ai-models/llm/Anthropic_LLMConfig.png)

Novaplan AI kann Claude-Modelle von Anthropic für KI-Funktionen in Ihrem Workspace verwenden. Novaplan unterstützt Sie bei der Einrichtung. Dafür benötigen Sie einen Anthropic-API-Schlüssel und die ID eines Modells, das Ihrem Konto zur Verfügung steht.

## Erforderliche Angaben

### API Key

Melden Sie sich in der [Anthropic Console](https://console.anthropic.com/) an, öffnen Sie **API Keys**, erstellen Sie einen neuen Schlüssel und kopieren Sie ihn sofort. Bewahren Sie ihn geschützt auf und veröffentlichen Sie ihn nicht. API-Nutzung zählt zu Kontingent und Abrechnung Ihres Anthropic-Kontos.

### Model Name

Der **Model Name** bestimmt das verwendete Claude-Modell. Beispiele sind `claude-opus-4-7` für anspruchsvolle Aufgaben, `claude-sonnet-4-6` als ausgewogene Option und `claude-haiku-4-6` für geringere Latenz. Modellangebot, Verfügbarkeit und Preise können sich ändern; prüfen Sie die [Anthropic-Modellübersicht](https://docs.anthropic.com/claude/docs/models-overview) und die Freigabe für Ihr Konto.

## Modell hinzufügen

1. Klicken Sie auf der Anthropic-Anbieterkarte auf **Configure**.
2. Tragen Sie den **API Key** ein.
3. Geben Sie unter **Model Name** die gewünschte Modell-ID ein.
4. Klicken Sie auf **Add Model**, um die Angaben zu speichern und prüfen zu lassen.

Beide Felder sind erforderlich. Bei Fehlern prüfen Sie Schlüssel, Schreibweise der Modell-ID, Kontozugang und Abrechnung. Für weitere Hilfe nutzen Sie die [Anthropic-Dokumentation](https://docs.anthropic.com/) oder [Novaplan Support](/de/contact-us).
