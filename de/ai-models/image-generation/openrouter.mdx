# OpenRouter Bildgenerierung konfigurieren

Über OpenRouter kann Novaplan AI Bildmodelle verschiedener Anbieter ansprechen. Novaplan unterstützt Sie bei der Einrichtung.

## Erforderliche Angaben

**API Key:** Erstellen Sie unter **Keys** in Ihrem [OpenRouter-Konto](https://openrouter.ai/) einen Schlüssel. Er beginnt üblicherweise mit `sk-or-`. Bewahren Sie ihn geschützt auf.

**Model Name:** Geben Sie die genaue ID eines verfügbaren Bildmodells im Format `anbieter/modell` ein. Beispiele sind `bytedance-seed/seedream-4.5` und `black-forest-labs/flux.2-pro`. Prüfen Sie den [aktuellen OpenRouter-Modellkatalog](https://openrouter.ai/models), den Zugang Ihres Kontos und die Kosten.

Mit **Model Friendly Name** können Sie optional einen verständlichen Anzeigenamen festlegen. Für Sprachmodelle gibt es eine separate [OpenRouter-Anleitung](/de/ai-models/llm/openrouter). [Novaplan Support](/de/contact-us) hilft bei der Einrichtung.
