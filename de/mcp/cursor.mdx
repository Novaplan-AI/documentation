Cursor kann sich über OAuth mit dem entfernten MCP-Endpunkt Ihres Novaplan AI Workspaces verbinden. Dafür brauchen Sie eine OAuth-Anwendung mit **Client ID** und **Client Secret**. Die Einrichtung ist im [MCP-Überblick](/de/mcp/overview#schritt-1-oauth-anwendung-erstellen) beschrieben. Wenn Ihr Workspace noch nicht bereitsteht, wenden Sie sich an [Novaplan Support](/de/contact-us).

## MCP-Server konfigurieren

Öffnen Sie **Cursor Settings → Tools and Integrations → New MCP Server** oder bearbeiten Sie `.cursor/mcp.json` in Ihrem Projekt:

```json
{
  "mcpServers": {
    "novaplan": {
      "url": "NOVAPLAN_WORKSPACE_URL/mcp",
      "auth": {
        "CLIENT_ID": "YOUR_CLIENT_ID",
        "CLIENT_SECRET": "YOUR_CLIENT_SECRET",
        "scopes": [
          "openid", "profile", "email", "offline_access",
          "semantic:write", "conversation:write", "conversation:chat",
          "kb:read", "team:read", "user:read", "config:read"
        ]
      }
    }
  }
}
```

Ersetzen Sie die Platzhalter durch Ihre Workspace-Adresse und OAuth-Zugangsdaten. Der Name `novaplan` ist nur der lokale Eintrag in Cursor. Wählen Sie die Scopes passend zu den Werkzeugen, die die OAuth-Anwendung tatsächlich verwenden darf. Ohne ausdrückliche Liste verwendet Cursor laut aktueller Dokumentation `scopes_supported` aus `/.well-known/oauth-authorization-server`.

<Warning>
  Speichern Sie ein Client Secret nicht in einer Datei, die Sie ins Repository einchecken. Verwenden Sie für lokale Konfigurationen die von Cursor unterstützte Umgebungsvariablen-Interpolation wie `${env:NOVAPLAN_CLIENT_SECRET}` und schützen Sie die Werte entsprechend.
</Warning>

## Redirect-URIs registrieren

Tragen Sie in der Novaplan-OAuth-Anwendung die Redirect-URI für jede verwendete Cursor-Oberfläche ein:

| Cursor-Oberfläche | Redirect-URI |
| --- | --- |
| Desktop-App (aktuell) | `http://localhost:8787/callback` |
| Desktop-App (ältere Installationen) | `cursor://anysphere.cursor-mcp/oauth/callback` |
| Web und Cursor Agents | `https://www.cursor.com/agents/mcp/oauth/callback` |

Die aktuelle [Cursor-MCP-Dokumentation](https://cursor.com/docs/mcp#static-redirect-url) nennt für die Desktop-App die localhost-URI und für Web/Agents die HTTPS-URI. Einige ältere Desktop-Installationen verwenden weiterhin die `cursor://`-URI. Der zugängliche Novaplan-OAuth-Quellcode erlaubt sowohl diese ältere URI als auch localhost- und HTTPS-Weiterleitungen; die Enterprise-Version muss noch praktisch getestet werden. Bei einem Redirect-Fehler vergleichen Sie die von Cursor tatsächlich gesendete URI mit dem exakten Eintrag in der OAuth-Anwendung.

Wenn das interne Browserfenster die Novaplan-Anmeldung nicht lädt, öffnen Sie die angezeigte Autorisierungsadresse in Ihrem normalen Browser. Prüfen Sie bei einem OAuth-Fehler außerdem Redirect URI, Client-Zugangsdaten und Scopes.
