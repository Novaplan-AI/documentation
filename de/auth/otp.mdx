## So funktioniert die Anmeldung

Bei der Anmeldung mit **One-Time Password (OTP)** wird ein einmalig gültiger Code an Ihre E-Mail-Adresse gesendet:

1. Geben Sie Ihre E-Mail-Adresse ein.
2. Das System sendet einen Einmalcode an diese Adresse.
3. Geben Sie den Code auf der Anmeldeseite ein.
4. Nach erfolgreicher Prüfung erhalten Sie Zugriff.

In der aktuellen Implementierung ist ein Code **10 Minuten** gültig. Bei einem falschen oder abgelaufenen Code prüfen Sie die neueste E-Mail oder fordern einen neuen Code an. Fünf falsche Code- oder Passworteingaben können das Konto für 24 Stunden sperren; siehe [Schutz bei der Anmeldung](/de/auth#schutz-bei-der-anmeldung). Eine Code-Anforderung bestätigt aus Sicherheitsgründen nicht, ob zu der Adresse ein Konto besteht. Prüfen Sie den genauen Wortlaut und das Verhalten beim erneuten Versand im bereitgestellten Workspace.

Verwenden Sie die E-Mail-Adresse, an die Ihre Workspace-Einladung gesendet wurde. Wenn der Code nicht ankommt, prüfen Sie zunächst Ihren Spam-Ordner und wenden Sie sich dann an Ihre Workspace-Administration oder an [Novaplan Support](/de/contact-us).

## Für Administratoren

Novaplan übernimmt den Großteil der Einrichtung. Wenn Sie die Methode im Rahmen Ihrer Administratoraufgaben konfigurieren:

1. Öffnen Sie **Workspace Settings → Authentication**.
2. Aktivieren Sie **One-Time Password**.
3. Prüfen Sie, ob der Mailversand über SMTP eingerichtet ist und die Benutzer gültige E-Mail-Adressen haben.

<Warning>
  Ohne funktionierende SMTP-Konfiguration können Einmalcodes nicht per E-Mail zugestellt werden. Einzelheiten finden Sie in der [SMTP-Anleitung](/de/smtp).
</Warning>
