# Anthropic Configuration

![Anthropic Configuration Interface](/images/ai-models/llm/Anthropic_LLMConfig.png)

*The Anthropic configuration screen in Novaplan AI where you'll enter your API Key and Model Name*

Novaplan AI allows you to integrate with Anthropic's Claude models to enable powerful AI features in your workspace, providing sophisticated natural language understanding and generation capabilities.

## Required Fields

### API Key *

The Anthropic API Key is required to authenticate your requests to Anthropic's services.

**How to obtain an API Key:**
1. Log in to your [Anthropic Console](https://console.anthropic.com/)
2. Navigate to the "API Keys" section
3. Create a new API key
4. Copy the key immediately (it will only be shown once)

**Security Note:** Your API key should be kept secure and never shared publicly. Novaplan AI securely stores your API key and uses it only for authenticating requests to Anthropic.

### Model Name *

The Model Name field defines which Anthropic Claude model you want to use with Novaplan AI.

**Current Claude API examples include:**
- `claude-opus-5-5` - A starting point for demanding knowledge work
- `claude-sonnet-5` - A balance of speed and capability
- `claude-haiku-4-5` - A lower-latency option

**How to choose a model:**
- Compare the available models in Anthropic's [current model overview](https://platform.claude.com/docs/en/models/overview) and choose an ID enabled for your API key.
- Confirm the selected model and its features work with your Novaplan AI workspace before relying on it for production workflows. Anthropic may change model availability and pricing.

## Configuration Steps

As shown in the image above:

1. Click **Configure** on the Anthropic provider card
2. Enter your Anthropic API Key in the designated field (marked with *)
3. Specify your desired Model Name (marked with *)
4. Click **Add Model** to save and validate your credentials

> Both the API Key and Model Name are required fields to successfully configure Anthropic integration. You must complete these fields to proceed with the setup.

## Usage Considerations

- API usage will count against your Anthropic account's quota and billing
- Different models have different pricing - check Anthropic's [current pricing](https://platform.claude.com/docs/en/about-claude/pricing) for details
- Model capabilities vary - more powerful models may provide better results but at higher cost
- Claude models excel at:
  - Nuanced content generation
  - Detailed reasoning
  - Following complex instructions
  - Maintaining consistency in long conversations

## Troubleshooting

- If you encounter authentication errors, verify your API key is correct and has not expired
- Ensure your Anthropic account has billing set up if you're using paid models
- Check that the model name is spelled correctly and matches Anthropic's naming conventions
- Verify that your account has access to the model you've selected

For additional support, refer to the [Anthropic documentation](https://platform.claude.com/docs/en/) or [Novaplan AI support](/contact-us).
