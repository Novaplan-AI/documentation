# OpenRouter configuration

OpenRouter provides access to language models from multiple providers through one account. The available Novaplan AI provider configuration includes a dedicated **OpenRouter** option. Novaplan can help set up this connection in a managed workspace.

## Before you start

Create an account at [OpenRouter](https://openrouter.ai/) and generate an API key. Choose a model from the [current model catalog](https://openrouter.ai/models); availability, capabilities, and pricing depend on the model and your account. Keep the key private and arrange billing or credits as required by OpenRouter.

## Add a language model

1. In **AI Models**, choose to add a language model and select **OpenRouter** as the provider, if it is available in your workspace.
2. Enter your OpenRouter **API Key**.
3. Enter the exact **Model Name** from the catalog in `provider/model` format. Use the identifier shown for the model rather than a shortened display name.
4. Optionally set a **Model Friendly Name** and **Context Length** if you need to distinguish the configuration or specify its supported context window.
5. Enable **Is Multimodal** only if the selected model supports the image input you intend to use. Enable **Is Reasoning** only if the selected model supports reasoning. Check the model's current catalog entry before setting either option.
6. Save the model and test it in your workspace before using it with agents or customer data.

The dedicated OpenRouter configuration requires **API Key** and **Model Name**. It does not ask you to enter an endpoint URL. If your deployed workspace offers only **OpenAI API Compatible**, ask [Novaplan Support](/contact-us) to confirm the supported setup for your environment instead of assuming the provider form is identical.

## Troubleshooting

If authentication fails, verify the key in your OpenRouter account and check that the managed Novaplan service can reach OpenRouter. If the model is not found, copy its current full identifier from the catalog and check account access. For rate limits, unavailable models, or billing errors, review the model and account status in OpenRouter. [Novaplan Support](/contact-us) can help verify the connection in your workspace.

For embeddings, see [OpenRouter embedding configuration](/ai-models/embedding/openrouter).
