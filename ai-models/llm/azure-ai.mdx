# Azure AI Configuration

![Azure AI Configuration Interface](/images/ai-models/llm/AzureAI_LLMConfig.png)

*The Azure AI configuration screen in Novaplan AI where you'll enter your Endpoint URL, API Key, Model Name, and optional settings*

Novaplan AI can connect to a model deployment in Microsoft Foundry. Available model families, endpoints, billing, and regions depend on your Foundry resource and deployment. Novaplan helps you test the connection from your managed workspace.

## Required Fields

### Endpoint URL *

The Endpoint URL is required to connect to your Azure AI Foundry deployment. The URL format varies depending on the model type you're using.

**Endpoint formats depend on the deployed model and resource.** Microsoft's current [Foundry endpoint guide](https://learn.microsoft.com/en-us/azure/foundry/how-to/develop/sdk-overview) shows `https://<resource-name>.services.ai.azure.com/anthropic` for Claude deployments using the Anthropic Messages API and an `/openai/v1/` endpoint for OpenAI-compatible deployments. The latter may be under a `services.ai.azure.com` or `openai.azure.com` resource hostname. Copy your deployment's actual endpoint rather than substituting an example hostname.

**How to obtain your Endpoint:**
1. Log in to the [Azure Portal](https://portal.azure.com)
2. Navigate to your Azure AI Foundry resource (formerly Azure AI Studio)
3. Go to the model deployments section
4. Select your deployed model and copy the endpoint URL

**Note:** An older Novaplan form may still show `inference.ai.azure.com/anthropic` or `cognitiveservices.azure.com/openai/v1/` as a placeholder. Treat those as examples, not the address of your deployment. Confirm the value accepted by your Enterprise workspace with Novaplan.

### API Key *

The API Key authenticates your requests to your Azure AI service.

**How to obtain your API Key:**
1. In the Azure Portal, navigate to your Azure AI resource
2. Go to the "Keys and Endpoint" section in the left navigation
3. Copy either Key 1 or Key 2 (both will work)

**Security note:** Treat this API key as a secret. Use the approved workspace setup flow, and coordinate access and rotation with Novaplan and your provider administrator.

### Model Name *

The Model Name field identifies the Foundry deployment to call. Use the exact name assigned to your deployment; it need not match the base model's catalog ID. For a Claude deployment, have Novaplan verify that its provider selection routes requests to the Anthropic Messages endpoint.

**How to find available models:**
1. Visit the [Azure AI Foundry model catalog](https://ai.azure.com/explore/models)
2. Browse available models by capability or provider
3. Copy the exact deployment name, and check its region, API type, and enabled capabilities

## Optional Fields

### Context Length

Specify the maximum context length for your model (e.g., 128000 for 128K tokens). This helps Novaplan AI optimize how it handles large documents and conversations.

**Note:** Different models support different context lengths. Check your model's documentation for the maximum supported context.

### Multimodal

Enable this option if your model supports multimodal inputs (text + image). This allows Novaplan AI to process both text and images when interacting with the model.

Confirm image-input support for your deployed model and the API path Novaplan uses before enabling the checkbox.

### Reasoning

Enable this option if your model supports advanced reasoning capabilities. This is particularly useful for models designed for complex problem-solving tasks.

Confirm the selected deployment's reasoning controls and how the deployed Novaplan integration sends them before enabling the checkbox.

## Configuration Steps

As shown in the image above:

1. Select "Azure AI" as your Provider Type from the dropdown
2. Enter your Endpoint URL in the designated field (marked with *)
3. Enter your Azure AI API Key (marked with *)
4. Specify your Model Name (marked with *)
5. Optionally, set the Context Length for your model
6. Enable Multimodal if your model supports text + image inputs
7. Enable Reasoning if your model supports advanced reasoning
8. Click "Add Model" to complete the setup

> Endpoint URL, API Key, and Model Name are required fields. 
> You must complete these fields to proceed with the setup.

## Usage Considerations

- API usage will count against your Azure AI resource's quota and billing
- Different models have different pricing - check Azure's pricing page for details
- Model capabilities vary - more powerful models may provide better results but at higher cost
- Azure AI Foundry provides access to models from multiple providers with unified billing
- Enterprise features available include:
  - Virtual Network support
  - Role-based access control
  - Content filtering
  - Regional data residency

## Troubleshooting

- If you encounter authentication errors, verify your API key and endpoint URL are correct
- Ensure you're using the correct endpoint format for your model type (Claude vs. other models)
- Verify your Azure subscription is active and has sufficient quota for the selected model
- Check that the model name matches the exact name from your Azure AI deployment
- Ensure access from the managed Novaplan workspace is allowed if your Foundry resource has network restrictions
- For Claude models, verify you have access to the Anthropic models in Azure AI Foundry

For additional support, refer to the [Azure AI Foundry documentation](https://learn.microsoft.com/en-us/azure/ai-studio/) or contact Novaplan AI support.
