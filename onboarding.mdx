Novaplan AI creates your organization's workspace, prepares most settings, and invites your users. If you have received an invitation, follow [Getting started](/quickstart). You do not need to run system setup unless Novaplan has assigned that task to you.

<Info>
  This page is for administrators who need to review or complete an agreed setup. A workspace that is already configured may not show the initial setup screen. Keep existing settings unless a change has been agreed with Novaplan AI.
</Info>

## Initial system setup

The current setup flow covers an AI model, an embedding model, and storage. If Novaplan has configured these for your workspace, confirm they work before changing them.

<div id="step-1-configure-ai-model-required" />

### 1. AI model

An AI model is needed for AI-powered features. Choose a provider and model that Novaplan has approved for your workspace, or use an existing configured model. The available providers and fields depend on the selected provider. Enter credentials or an endpoint only when that provider requires them, then save the model and confirm it is selected as the default.

See [AI models](/ai-models/overview) for provider-specific settings. Do not copy a model ID or credential from a screenshot into your workspace.

### 2. Embedding model

An embedding model is needed to index content for semantic search. Select an existing configured embedding model, add an approved provider, or choose the system default if that option is offered. The **Skip** action, when shown, opens the system-default model path; it does not mean that search can run without embeddings. Save or select a model before continuing.

See [AI models](/ai-models/overview) for the supported provider configuration.

### 3. Storage

The setup flow offers local storage or Amazon S3. Local storage means storage available to the hosted workspace, not a folder on your computer. Novaplan normally prepares the appropriate storage setting. Change it only as agreed, and verify access before inviting users or syncing content. The storage step can be left at its existing local setting when that is the approved configuration.

See [external services](/system-overview/external-services) for the managed storage options. Azure Blob is supported by the platform but is not shown in the current initial setup screen.

## Settings managed outside initial setup

The following remain available as separate administrator tasks; they are not additional screens in the current initial setup flow:

- [Connectors](/connectors/overview): connect approved data sources after the workspace is ready. Credentials and access requirements differ by source.
- [Public service URLs](/system-overview/internal-services): Novaplan normally configures these for OAuth redirects and webhooks. Coordinate any production change with support.
- [Email delivery (SMTP)](/smtp): Novaplan normally configures the workspace mail service used for invitations and other email-based functions.

After setup, confirm that an invited user can sign in and use the intended features. If a setting is missing or an expected screen differs, contact [Novaplan AI support](mailto:support@novaplan.ai).
