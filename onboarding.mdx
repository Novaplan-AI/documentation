Diese Anleitung richtet sich an Administratoren, die einen neuen Novaplan-Arbeitsbereich einrichten. Wenn Ihr Arbeitsbereich bereits vorbereitet wurde, melden Sie sich mit Ihrer Einladung an. Einstellungen und verfügbare Anbieter können je nach Version abweichen.

<Note>
  Englische Bezeichnungen stehen ergänzend in Klammern, damit Sie die Felder auch in einer englischen Benutzeroberfläche wiederfinden.
</Note>

## 1. KI-Modell konfigurieren

Ein Sprachmodell ist erforderlich, um die KI-Funktionen zu nutzen.

1. Wählen Sie den bereitgestellten KI-Anbieter aus.
2. Tragen Sie die erforderlichen Zugangsdaten ein, beispielsweise den API-Schlüssel und gegebenenfalls einen Endpunkt oder eine Client-ID.
3. Geben Sie den exakten Modellnamen des Anbieters ein.
4. Klicken Sie auf **Weiter (Continue)**.

Die [KI-Modellreferenz](/ai-models/overview) beschreibt die einzelnen Anbieter auf Englisch.

## 2. Embedding-Modell konfigurieren

Embedding-Modelle wandeln Dokumentinhalte in Vektoren um. Diese werden für die semantische Suche verwendet.

1. Wählen Sie einen verfügbaren Embedding-Anbieter aus.
2. Geben Sie bei Bedarf den Endpunkt und den API-Schlüssel ein.
3. Tragen Sie den Namen eines **Embedding-Modells** ein. Ein reines Chatmodell ist dafür nicht geeignet.
4. Klicken Sie auf **Weiter (Continue)**.

Wenn der Einrichtungsdialog das Überspringen anbietet, können Sie diesen Schritt später nachholen. Prüfen Sie vor dem Indexieren von Dokumenten, dass ein passendes Embedding-Modell eingerichtet ist.

## 3. Speicher konfigurieren

Standardmäßig werden Dateien im lokalen Speicher abgelegt. Je nach Bereitstellung können Sie stattdessen Amazon S3 oder Azure Blob Storage verwenden.

| Speicher | Typische Angaben |
| --- | --- |
| Lokal | Mount-Name und Basis-URL |
| Amazon S3 | Bucket, Zugriffsschlüssel und geheimer Schlüssel |
| Azure Blob Storage | Konto, Container, Kontoschlüssel, Protokoll und Endpunktsuffix |

Speichern Sie mit **Weiter (Continue)**. Details finden Sie in der englischen [Speicherreferenz](/system-overview/storage).

## 4. Öffentliche URLs prüfen

Die URLs Ihrer Novaplan-Anwendung und des Konnektordienstes werden für OAuth-Anmeldungen, Weiterleitungen und Webhooks benötigt.

1. Prüfen Sie den Frontend-Endpunkt Ihrer tatsächlichen Novaplan-Instanz.
2. Prüfen Sie den Konnektor-Endpunkt Ihrer Bereitstellung.
3. Speichern Sie mit **Weiter (Continue)**.

<Info>
  docs.novaplan.ai ist die Dokumentationsadresse. Verwenden Sie diese Adresse nicht als Anwendungs-, API- oder OAuth-Endpunkt.
</Info>

Weitere Informationen stehen in der englischen [Referenz zu internen Diensten](/system-overview/internal-services).

## 5. Datenquellen verbinden

Konnektoren synchronisieren Inhalte aus externen Anwendungen. Die benötigten Zugangsdaten und Berechtigungen unterscheiden sich je nach Dienst und Verbindungsart.

Für eine persönliche Google-Verbindung werden beispielsweise eine OAuth-Client-ID und ein Client-Secret benötigt. Die angezeigte Redirect-URI muss exakt in der Google Cloud Console eingetragen werden. Eine organisationsweite Verbindung kann stattdessen ein Dienstkonto und eine Administratoradresse erfordern.

Beginnen Sie mit der [Konnektorenübersicht](/connectors/overview). Die [Google-Drive-Referenz](/connectors/google-workspace/drive/drive) beschreibt die technischen Schritte.

Sie können Konnektoren später in den Einstellungen ergänzen.

## 6. E-Mail-Versand einrichten

SMTP wird für Einladungen, Einmalcodes und das Zurücksetzen vergessener Passwörter benötigt.

1. Geben Sie die SMTP-Serveradresse Ihres E-Mail-Anbieters ein.
2. Tragen Sie den vom Anbieter vorgegebenen Port und die passende Verschlüsselung ein.
3. Ergänzen Sie Benutzername und Passwort.
4. Legen Sie eine zulässige Absenderadresse fest.
5. Speichern Sie die Einstellungen.

Die englische [SMTP-Anleitung](/smtp) enthält die Konfigurationsdetails. Wenn Sie diesen Schritt überspringen, stehen Funktionen, die einen E-Mail-Versand benötigen, möglicherweise noch nicht zur Verfügung.

## Einrichtung abschließen

Prüfen Sie anschließend, ob eine Testfrage beantwortet wird, verbundene Dokumente nach der Indexierung gefunden werden und Einladungen zugestellt werden. Danach können Sie [Mitglieder einladen](/user-management/user) und Ihren [ersten Agenten erstellen](/agent-guide/setup-guide).
