---
title: "Benutzergruppen"
description: "Mitglieder in Gruppen organisieren und gruppenbezogene Zugriffe verwalten."
---

Benutzergruppen helfen Administratoren, Mitglieder nach Aufgaben, Abteilungen oder Zugriffsbedarf zu organisieren. Eine Person kann mehreren Gruppen angehören; jede Gruppe kann mehrere Mitglieder enthalten.

## Gruppenübersicht öffnen

1. Melden Sie sich als Administrator an.
2. Öffnen Sie **Arbeitsbereichseinstellungen (Workspace Settings)**.
3. Wählen Sie unter **Personen (People)** den Eintrag **Gruppen (Groups)**.

Die Übersicht zeigt Name, Beschreibung, Mitgliederzahl, Ersteller und Erstellungsdatum. Nutzen Sie die Suche und den Datumsfilter. Ein Klick auf eine Gruppe öffnet ihre Details.

## Gruppe erstellen

1. Klicken Sie auf **Gruppe erstellen (Create Group)**.
2. Geben Sie einen Gruppennamen ein, beispielsweise „Projektleitung“.
3. Ergänzen Sie bei Bedarf eine Beschreibung.
4. Wählen Sie unter **Benutzer hinzufügen (Add Users)** die ersten Mitglieder aus.
5. Bestätigen Sie mit **Gruppe erstellen (Create Group)**.

Neben eigenen Gruppen gibt es Systemgruppen, beispielsweise eine Gruppe für alle Mitglieder. Systemgruppen können nicht gelöscht werden.

<Note>
  Der Bereich **Zugriffsberechtigungen (Access Permissions)** ist in der Ausgangsversion als noch nicht verfügbar gekennzeichnet. Die tatsächlichen Zugriffsmöglichkeiten richten sich nach der eingesetzten Version und der vorhandenen Gruppenanbindung.
</Note>

## Mitglieder hinzufügen

Bei einer [Benutzereinladung](/user-management/user) können Sie die Gruppen direkt im Feld **Zu einer Benutzergruppe hinzufügen (Add to a User Group)** zuweisen.

Für bestehende Mitglieder:

1. Öffnen Sie die gewünschte Gruppe.
2. Klicken Sie auf **Gruppe bearbeiten (Edit Group)**.
3. Suchen Sie unter **Benutzer hinzufügen (Add Users)** nach den Mitgliedern und wählen Sie sie aus.
4. Klicken Sie auf **Änderungen speichern (Save Edits)**.

## Mitglieder entfernen

1. Öffnen Sie die Gruppe und wählen Sie **Gruppe bearbeiten (Edit Group)**.
2. Klicken Sie neben dem Mitglied auf **Entfernen (Remove)**.
3. Mit **Rückgängig (Undo)** können Sie die vorgemerkte Entfernung vor dem Speichern zurücknehmen.
4. Speichern Sie die Änderungen.

## Name oder Beschreibung ändern

Öffnen Sie die Gruppendetails, wählen Sie **Gruppe bearbeiten (Edit Group)** und ändern Sie den Namen oder die Beschreibung. Bestätigen Sie mit **Änderungen speichern (Save Edits)**.

## Gruppe löschen

1. Öffnen Sie die Gruppendetails.
2. Wählen Sie **Gruppe löschen (Delete Group)** oder **Löschen (Delete)** im Menü **⋯**.
3. Bestätigen Sie die Aktion.

<Warning>
  Das Löschen lässt sich nicht rückgängig machen. Die Benutzerkonten bleiben bestehen, verlieren aber die aus dieser Gruppe abgeleiteten Berechtigungen. Systemgruppen können nicht gelöscht werden.
</Warning>

Für die Zusammenarbeit mit unterschiedlichen Rollen innerhalb eines Teams lesen Sie die Anleitung zu [Teams](/user-management/teams).
