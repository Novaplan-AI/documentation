---
title: "Benutzer verwalten"
description: "Mitglieder in Ihren Novaplan-Arbeitsbereich einladen, Einladungen verwalten und Zugänge entfernen."
---

Auf der Seite **Benutzer (Users)** sehen Administratoren die Mitglieder ihres Arbeitsbereichs und offene Einladungen.

## Benutzerübersicht öffnen

1. Melden Sie sich mit einem Administratorkonto an.
2. Öffnen Sie im Benutzermenü **Arbeitsbereichseinstellungen (Workspace Settings)**.
3. Wählen Sie unter **Personen (People)** den Eintrag **Benutzer (Users)**.

Die Tabelle zeigt Name, E-Mail-Adresse, Rolle, Gruppenzugehörigkeit, Status, letzte Aktivität und Beitrittsdatum. Über die Suche finden Sie Mitglieder nach Name oder E-Mail-Adresse. Mit Filtern grenzen Sie die Liste beispielsweise nach Gruppe oder Status ein. Ein Klick auf eine Zeile öffnet das Profil.

## Mitglieder einladen

1. Klicken Sie oben rechts auf **Einladen (Invite)**.
2. Tragen Sie eine oder mehrere E-Mail-Adressen in **Einladen an (Invite to)** ein. Trennen Sie mehrere Adressen mit Komma, Leerzeichen oder Eingabetaste.
3. Wählen Sie bei Bedarf unter **Zu einer Benutzergruppe hinzufügen (Add to a User Group)** passende Gruppen aus.
4. Klicken Sie auf **Einladung senden (Send Invite)**.

Die eingeladenen Personen erhalten eine E-Mail mit den nächsten Schritten. Bis zur ersten Anmeldung lautet ihr Status **Ausstehend (Pending)**. Für die Zustellung muss [SMTP](/smtp) eingerichtet sein.

## Offene Einladungen bearbeiten

Öffnen Sie das Menü **⋯** neben einer ausstehenden Einladung:

- **Einladung erneut senden (Resend Invite)** versendet die Einladung erneut.
- **Einladung abbrechen (Cancel Invite)** zieht die offene Einladung zurück.

Diese Optionen stehen auch bei abgelaufenen Einladungen zur Verfügung.

## Mehrere Einträge bearbeiten

Markieren Sie die gewünschten Zeilen über die Kontrollkästchen. Die Aktionsleiste bietet bei ausschließlich ausstehenden Einladungen das erneute Senden oder Abbrechen an.

Bei anderen Auswahlen steht **Aus dem Arbeitsbereich entfernen (Remove from Workplace)** zur Verfügung. Enthält die Auswahl ein Administratorkonto, ist das Entfernen deaktiviert.

## Aktive und gesperrte Benutzer

Für aktive Mitglieder können Sie im Zeilenmenü das Profil öffnen oder den Zugang entfernen. Die Funktion **Deaktivieren (Deactivate)** ist in der Ausgangsversion als noch nicht verfügbar gekennzeichnet.

Bei einem gesperrten Benutzer wählen Sie **Entsperren (Unblock)**. Bestätigen Sie die Aktion, indem Sie den angezeigten Namen eingeben.

Administratorkonten lassen sich auf dieser Seite nicht entfernen; im Zeilenmenü steht nur die Profilansicht bereit.

## Benutzer entfernen

1. Öffnen Sie das Menü **⋯** des betreffenden Mitglieds.
2. Wählen Sie **Aus dem Arbeitsbereich entfernen (Remove from Workplace)**.
3. Bestätigen Sie mit **Entfernen (Remove)**.

<Warning>
  Das Mitglied verliert unmittelbar den Zugang zum Arbeitsbereich. Seine Gruppenzugehörigkeiten werden entfernt. Prüfen Sie vor der Bestätigung, ob Sie das richtige Konto ausgewählt haben.
</Warning>
