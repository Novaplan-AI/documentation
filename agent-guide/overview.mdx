Agenten sind anpassbare KI-Assistenten für bestimmte Aufgaben. Sie können Dokumente durchsuchen und über freigegebene Werkzeuge Aktionen in verbundenen Anwendungen ausführen.

## Die Bausteine eines Agenten

| Baustein | Aufgabe |
| --- | --- |
| Agent Core | Name, Beschreibung, Begrüßung und Verhaltensanweisungen festlegen. |
| Reasoning Model | Das KI-Modell bereitstellen, das die Aufgabe verarbeitet. |
| Wissensquellen | Indexierte Daten aus Konnektoren und hochgeladene Sammlungen bereitstellen. |
| Toolsets | Werkzeuge für externe Anwendungen verfügbar machen. |

Im visuellen Editor ziehen Sie die benötigten Bausteine auf die Arbeitsfläche und verbinden sie mit dem **Agent Core**.

## Anweisungen festlegen

Im Agent Core definieren Sie:

- **Name:** den angezeigten Namen,
- **Beschreibung (Description):** den vorgesehenen Zweck,
- **Startnachricht (Start Message):** die Begrüßung zu Beginn eines Chats,
- **Anweisung (Instruction):** die Aufgaben und Fähigkeiten,
- **System Prompt:** das gewünschte Verhalten, die Sprache und Grenzen des Agenten.

Formulieren Sie konkret, welche Quellen verwendet werden sollen und welche Aktionen der Agent ausführen darf.

## Wissen durchsuchen oder Aktionen ausführen

**Konnektoren** synchronisieren Daten für die Suche. **Toolsets** ermöglichen den Zugriff auf Werkzeuge, die beispielsweise Nachrichten versenden, Tickets erstellen oder Inhalte bearbeiten.

Ein Gmail-Konnektor erschließt beispielsweise E-Mails für die Suche. Ein Gmail-Toolset kann einem Agenten das Versenden neuer E-Mails ermöglichen.

Für einen Agenten, der beides benötigt, fügen Sie Wissensquellen aus **Knowledge** und Werkzeuge aus **Tools** hinzu und verbinden beide mit dem Agent Core.

## Toolsets

Beispiele für mögliche Werkzeuge:

- **Jira:** Tickets erstellen, suchen und kommentieren.
- **Slack:** Nachrichten versenden und Kanäle durchsuchen.
- **Confluence:** Seiten finden, erstellen und bearbeiten.
- **Gmail:** E-Mails lesen, suchen und versenden.
- **Calendar:** Termine erstellen und Verfügbarkeiten prüfen.
- **Drive:** Dateien suchen und Ordner verwalten.

<Info>
  Ein Toolset muss eingerichtet und authentifiziert sein, bevor Sie es dem Agenten zuordnen. Die [Toolset-Referenz](/toolsets/overview) beschreibt die Einrichtung auf Englisch.
</Info>

## Wissensquellen

Über Konnektoren indexierte Anwendungen und eigene Sammlungen stehen als Wissensquellen zur Verfügung. Verbinden Sie nur die Quellen, die der Agent für seine Aufgabe benötigt.

## Häufige Fragen

<AccordionGroup>
  <Accordion title="Kann ich mehrere Modelle verbinden?">
    Ja. Sie können mehrere Reasoning-Modelle mit dem Agent Core verbinden. Im Chat lässt sich je nach verfügbarer Oberfläche auswählen, welches Modell für eine Anfrage verwendet wird.
  </Accordion>
  <Accordion title="Kann ich im Chat Quellen und Werkzeuge auswählen?">
    Die Chatoberfläche unterstützt die Auswahl bestimmter Sammlungen, Toolsets und Modelle. So können Sie beispielsweise eine Suche auf Confluence begrenzen oder für eine Aktion Gmail auswählen.
  </Accordion>
  <Accordion title="Kann dieselbe OAuth-App für Konnektor und Toolset verwendet werden?">
    Je nach Anbieter kann dieselbe OAuth-App verwendet werden. Hinterlegen Sie dann beide angezeigten Callback-URLs und die jeweils benötigten Berechtigungen. Die Redirect-URLs für Konnektor und Toolset unterscheiden sich. Folgen Sie der Referenz des jeweiligen Dienstes.
  </Accordion>
  <Accordion title="Welche Verbindungen sind erforderlich?">
    Ein Agent benötigt einen Agent Core und mindestens ein passendes Reasoning-Modell. Wissensquellen und Toolsets sind optional. Prüfen Sie, dass die verwendeten Bausteine mit dem Agent Core verbunden sind.
  </Accordion>
</AccordionGroup>
