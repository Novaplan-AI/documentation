## Voraussetzungen

- Mindestens ein KI-Modell mit aktivierter Reasoning-Unterstützung ist eingerichtet.
- Benötigte Toolsets sind konfiguriert und authentifiziert.
- Benötigte Wissensquellen sind verbunden und indexiert.

Die englischen Bezeichnungen in Klammern helfen Ihnen, die entsprechenden Elemente auch in einer englischen Oberfläche zu finden.

## 1. Agentenbereich öffnen

Öffnen Sie **Agenten (Agent / Agent Beta)** in der Navigation. Die Verwaltungsseite zeigt vorhandene Agenten. Klicken Sie auf **Neuer Agent (+ New Agent)**.

## 2. Agent Core konfigurieren

Der visuelle Editor öffnet sich mit einem Agent-Core-Baustein. Über das Stiftsymbol öffnen Sie dessen Konfiguration.

| Feld | Beispiel |
| --- | --- |
| Beschreibung (Description) | Unterstützt die Projektleitung bei Tickets und Projektdokumentation. |
| Startnachricht (Start Message) | Wobei kann ich Ihnen in Ihrem Projekt helfen? |
| Anweisung (Instruction) | Suche relevante Projektdokumente und hilf beim Formulieren von Jira-Tickets. |
| System Prompt | Antworte auf Deutsch, nenne Quellen und frage vor dem Erstellen oder Ändern von Tickets nach einer Bestätigung. |

Speichern Sie mit **Änderungen speichern (Save Changes)**. Stimmen Sie die Anweisungen auf den tatsächlichen Aufgabenbereich und die erlaubten Aktionen ab.

## 3. KI-Modell verbinden

1. Öffnen Sie **LLM Models** in der linken Seitenleiste.
2. Ziehen Sie ein passendes Modell auf die Arbeitsfläche.
3. Verbinden Sie den Ausgang des **Agent Core** mit dem Eingang des **MODEL PROVIDER**.

Ein Agent benötigt mindestens ein verbundenes Reasoning-Modell.

## 4. Werkzeuge hinzufügen

1. Öffnen Sie **Tools** und anschließend **APPLICATIONS**.
2. Wählen Sie ein authentifiziertes Toolset aus.
3. Ziehen Sie das gesamte Toolset oder einzelne benötigte Werkzeuge auf die Arbeitsfläche.
4. Verbinden Sie den Baustein mit dem Agent Core.

Einzelne Werkzeuge können Sie innerhalb des Toolset-Bausteins entfernen. Über die Löschfunktion des Bausteins entfernen Sie das gesamte Toolset.

Die [Toolset-Referenz](/toolsets/overview) erläutert die verfügbaren Aktionen auf Englisch.

## 5. Wissensquellen hinzufügen

1. Öffnen Sie **Knowledge** in der Seitenleiste.
2. Wählen Sie **Apps** für indexierte Anwendungen oder **Collections** für hochgeladene Dokumentensammlungen.
3. Ziehen Sie die gewünschte Quelle auf die Arbeitsfläche.
4. Verbinden Sie sie mit dem Agenten.

Die integrierte Suche **Internal Retrieval** kann indexierte Inhalte durchsuchen und benötigt keine zusätzliche Toolset-Einrichtung.

## 6. Agenten speichern

Geben Sie oben auf der Seite einen Namen ein und klicken Sie auf **Agent speichern (Save Agent)**.

## 7. Agenten testen

Öffnen Sie den Agenten über die Verwaltungsseite und starten Sie einen Chat. Prüfen Sie zunächst eine Frage zu einer bekannten Quelle. Testen Sie anschließend die vorgesehenen Werkzeuge mit einer geeigneten Testaufgabe.

Kontrollieren Sie, ob der Agent passende Quellen verwendet, seine Anweisungen einhält und nur die vorgesehenen Aktionen ausführt. Überarbeiten Sie bei Bedarf die Anweisungen und die verbundenen Quellen.

## Probleme beheben

<AccordionGroup>
  <Accordion title="Ein Toolset erscheint nicht">
    Prüfen Sie unter **Einstellungen → Toolsets (Settings → Toolsets)**, ob es eingerichtet ist und die Anmeldung abgeschlossen wurde. Kehren Sie danach zum Agenten-Editor zurück.
  </Accordion>
  <Accordion title="Der Agent antwortet nicht oder läuft in eine Zeitüberschreitung">
    Prüfen Sie die KI-Modellkonfiguration und die Reasoning-Unterstützung. Erneuern Sie gegebenenfalls abgelaufene Toolset-Anmeldungen. Testen Sie anschließend mit vereinfachten Anweisungen.
  </Accordion>
  <Accordion title="Die Wissenssuche liefert keine Ergebnisse">
    Prüfen Sie den Synchronisierungsstatus der Konnektoren und den Inhalt Ihrer Sammlungen. Warten Sie, bis die Indexierung abgeschlossen ist, und kontrollieren Sie die Suchfilter und Zugriffsrechte.
  </Accordion>
  <Accordion title="Der Agent lässt sich nicht speichern">
    Prüfen Sie den Namen, die Verbindung zu mindestens einem Reasoning-Modell und die Verbindungen zwischen den Bausteinen.
  </Accordion>
</AccordionGroup>

Mehr zu den Bausteinen finden Sie unter [KI-Agenten verstehen](/agent-guide/overview).
