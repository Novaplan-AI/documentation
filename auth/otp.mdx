## Sign in with a one-time code

One-Time Password (OTP) sign-in sends a single-use code to your email address:

1. Enter the email address used for your Novaplan AI workspace invitation.
2. Check your inbox for the one-time code.
3. Enter the code on the sign-in page.
4. After the code is verified, you can access your workspace.

If the code does not arrive, check your spam folder and then contact your workspace administrator or [Novaplan Support](/contact-us).

## For administrators

Novaplan manages most workspace setup. If configuring this method is part of your administrator role:

1. Open **Workspace Settings → Authentication**.
2. Enable **One-Time Password**.
3. Confirm that workspace email delivery through SMTP works and users have valid email addresses.

<Warning>
  Without working SMTP configuration, users cannot receive one-time codes. See the [SMTP guide](/smtp) for setup details.
</Warning>
