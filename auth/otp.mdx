## Mit einem Einmalcode anmelden

1. Geben Sie Ihre E-Mail-Adresse auf der Anmeldeseite ein.
2. Novaplan sendet einen Einmalcode an diese Adresse.
3. Geben Sie den Code im Anmeldedialog ein.
4. Nach erfolgreicher Prüfung erhalten Sie Zugang.

## Einmalcodes aktivieren

Als Administrator öffnen Sie die Authentifizierungseinstellungen und aktivieren **Einmalcode (One-Time Password)**. Alle Benutzer benötigen eine gültige E-Mail-Adresse.

<Warning>
  Einmalcodes benötigen einen funktionierenden E-Mail-Versand. Richten Sie [SMTP](/smtp) ein und prüfen Sie die Zustellung, bevor Sie diese Anmeldemethode einsetzen.
</Warning>

## Es kommt kein Code an

Prüfen Sie die eingegebene E-Mail-Adresse und Ihren Spam-Ordner. Lassen Sie Ihren Administrator anschließend die SMTP-Einstellungen und die Zustellung beim E-Mail-Anbieter prüfen.
