Custom Instructions let you guide how the Novaplan AI Chat Assistant responds, for example by specifying a preferred language or response format.

<Info>
  These instructions apply to the **Chat Assistant in Agent mode**. Agents created in **Agent Builder** use their own instructions. Change workspace settings only when this is part of the setup responsibility agreed with Novaplan.
</Info>

## Add instructions

1. Open **Custom Instructions** in your workspace settings.
2. Enter your instructions in the **Agent** section.
3. Select **Save** in the bar that appears when you make changes.
4. Start a new conversation in Agent mode and check the response.

Agent mode can choose internal knowledge, web search, or both for a question. Instructions can guide that behavior and the response style.

For example:

```text
Respond in German and address the reader as Sie.
Begin with a short summary, then list the relevant details.
Prefer internal knowledge for questions about our projects.
If the available sources do not establish an answer, say what is missing.
```

Use a few specific instructions and test them with typical questions. If you change several behaviors at once, it can be harder to identify which instruction needs adjustment.

## Save, discard, or reset

| Action | Result |
| --- | --- |
| **Save** | Saves the workspace's custom instructions. Test them in a new conversation. |
| **Discard changes** | Restores the last saved text and discards unsaved edits. |
| **Reset to Default** | Clears the custom instructions in the editor. Select **Save** to apply the reset. |

## Troubleshooting

If a change does not appear to take effect, check that it was saved and start a new Chat Assistant conversation in Agent mode. For an agent created in Agent Builder, review that agent's own instructions instead.

If the settings are unavailable or you are unsure who should manage them, contact [Novaplan support](/contact-us).
