Web search lets the assistant use public web sources when answering a question. This complements the internal content made available through your workspace's connected sources.

In Chat Assistant Agent mode, the assistant decides whether to use internal knowledge, web search, or both. Review the cited sources when using an answer.

## Who manages the settings?

The **Web Search Configuration** page is for workspace administrators. Customers do not need to configure a provider simply to use an already configured workspace.

<Info>
  Novaplan may manage these settings as part of your workspace setup. Only change them when this responsibility has been agreed with Novaplan. If the page shows inherited settings, contact [support](/contact-us) before replacing them with a workspace-specific configuration.
</Info>

## Available providers

| Provider | Configuration |
| --- | --- |
| DuckDuckGo | Built-in; no API key is required. |
| Serper | Requires a provider API key. |
| Tavily | Requires a provider API key. |
| Exa | Requires a provider API key. |

Several providers can be configured. One is selected as the workspace default.

## Configure a provider

1. Open **Web Search Configuration** in your workspace settings.
2. Choose **Configure** for the provider you want to use.
3. Enter the provider API key in **API Key** and select **Save**.
4. Select **Set as default** on the configured provider to make it the workspace default.
5. Check the **Default** badge, then try a question that requires information from the web.

To change an existing API key, open **Edit configuration** and select **Update** after making your changes. Saving a new provider configuration and choosing it as the default are separate actions.

## Image settings

Under **Image Settings**, **Send images to LLM** controls whether web search images are sent to the language model. The switch saves its change immediately.

When enabled, **Maximum input images per LLM call** accepts a whole number from 1 to 500. Press Enter or leave the field to apply the value. Including images may increase processing time and model usage costs.

## Remove a provider

Use **Delete configuration** to remove a provider's saved configuration. The page checks whether agents use it and blocks deletion while those dependencies remain. Update the affected agents before trying again.

Deleting the default provider resets the workspace default to DuckDuckGo.

## Need help?

If configuration fails, check the provider name and the error shown on the page. Contact [Novaplan support](/contact-us) if you need help with your workspace's setup, including settings managed by Novaplan. Do not include API keys in support messages.
