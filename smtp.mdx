# Email delivery (SMTP)

Novaplan AI uses its workspace mail configuration to send messages such as invitations, one-time codes, and password reset emails. Novaplan normally prepares this setting. An administrator should change it only after agreeing on the sender and mail service with the Novaplan team.

<Info>
  SMTP is configured separately from the initial AI model, embedding model, and storage setup. A workspace may inherit its mail settings from its managed deployment.
</Info>

## Check or change the configuration

1. Sign in with a workspace administrator account and open **Workspace → Mail**.
2. Check whether the SMTP entry shows **Configured**. If it is inherited or already works, keep the current settings unless Novaplan has requested a change.
3. To configure an agreed mail service, open the SMTP settings panel. Enter the host, port, and sender email address. Add a username and password only if the mail provider requires authentication.
4. Save the settings and test delivery with an invitation or other approved test message. Check the sender address and spam filtering if the message does not arrive.

The current settings form requires **SMTP Host**, **Port**, and **From Email Address**. The port defaults to `587` in the form; use the value and security settings specified by your mail provider. Credentials are optional when the provider does not require them. Store them in the configuration form, not in documentation or support messages.

<Warning>
  Changing the mail service can interrupt invitations, one-time codes, and password resets. Coordinate production changes with Novaplan AI and confirm delivery before relying on the new settings.
</Warning>

## If mail is not arriving

- Confirm that the SMTP entry is configured and the sender address is accepted by your provider.
- Check the provider's current host, port, authentication, and transport requirements.
- Check the recipient's spam folder and your mail provider's delivery logs.
- If the workspace inherits its mail configuration or you cannot access the settings, contact [Novaplan AI support](mailto:support@novaplan.ai).
