LibreChat supports remote MCP servers with OAuth authentication through its MCP Settings panel. This lets you use Novaplan AI tools with supported models in your LibreChat instance.

<Note>
  Before you start, create an OAuth app in Novaplan AI and note your **Client ID** and **Client Secret**. See [MCP Server Overview](/mcp/overview#step-1-create-an-oauth-app).
</Note>

## Configuration

<Steps>
  <Step title="Open MCP Servers settings">
    Log in to your LibreChat instance and navigate to the **MCP Servers** settings panel.
  </Step>
  <Step title="Add a new connector">
    Click **Add** to create a new custom MCP connector and fill in the details:
    - **Name**: `Novaplan AI` (or any name you prefer)
    - **MCP Server URL**: `NOVAPLAN_WORKSPACE_URL/mcp`
    - **Transport**: Select **Streamable HTTP** for the HTTPS endpoint
    - **Authentication**: Select **OAuth**
  </Step>
  <Step title="Enter OAuth credentials">
    Enter your OAuth credentials:
    - **Client ID**: `YOUR_CLIENT_ID`
    - **Client Secret**: `YOUR_CLIENT_SECRET`
    - **Authorization URL**: `NOVAPLAN_WORKSPACE_URL/api/v1/oauth2/authorize`
    - **Token URL**: `NOVAPLAN_WORKSPACE_URL/api/v1/oauth2/token`
    - **Scope**: Enter the space-separated scopes approved for the tools you will use. For the documented search and chat tools, review `openid profile email offline_access semantic:write conversation:write conversation:chat kb:read team:read user:read config:read` with your Novaplan administrator rather than granting it by default.
  </Step>
  <Step title="Trust and save">
    Review the trust prompt and click **Create** to save the server. LibreChat registers an OAuth-enabled server but leaves it disconnected until a user authenticates.
  </Step>
  <Step title="Register the redirect URI">
    The callback uses your LibreChat base URL and the **server name** you created. Copy the actual callback from your instance when it is shown, or confirm it with its administrator. A local instance commonly uses this format:
    ```
    http://localhost:3080/api/mcp/<server-name>/oauth/callback
    ```
    Copy the Redirect URI and register it as an allowed redirect URI in your Novaplan AI OAuth app (see [Step 1](/mcp/overview#step-1-create-an-oauth-app)).
  </Step>
  <Step title="Authenticate">
    Return to LibreChat and use the server's **Authenticate/Connect** control in MCP Settings or the chat server menu. Complete the Novaplan AI login and consent flow. Each LibreChat user authenticates individually.
  </Step>
</Steps>

## Redirect URI

LibreChat's MCP OAuth callback follows this format:

```
http://localhost:3080/api/mcp/<server-name>/oauth/callback
```

Here `<server-name>` is the MCP **server name** you chose in LibreChat, not a separate ID generated after creation. You must register the exact URI in your Novaplan AI OAuth app **before** authenticating. See [LibreChat's MCP guide](https://www.librechat.ai/docs/features/mcp#oauth-callback-url) for the current callback format.

<Note>
  If your LibreChat instance runs on a different host or port, the URI will reflect that (e.g., `https://chat.example.com/api/mcp/novaplan/oauth/callback`). Use the exact server name and callback shown by your LibreChat instance.
</Note>

## Scopes

LibreChat allows you to specify the OAuth scopes in the **Scope** field. Use a space-separated list:

```
openid email
```

To request Novaplan AI-specific scopes, add them to the scope field:

```
openid profile email offline_access semantic:write conversation:write conversation:chat kb:read team:read user:read config:read
```

<Note>
  Every requested scope must be allowed for your Novaplan AI OAuth app; the app may allow additional scopes that LibreChat does not request. See [Customizing Default Scopes](/mcp/overview#customizing-default-scopes) for details.
</Note>
