## API Documentation

These service pages include source-derived internal and administrative routes. They are a technical reference, not a promise that every endpoint is enabled or supported for customer integrations in the deployed Novaplan Enterprise workspace. Confirm the available API contract and required permissions with [Novaplan Support](/contact-us) before building against a route. Use only interfaces Novaplan has approved for your integration.

### Crawling Manager Service
Automated data ingestion and synchronization across multiple enterprise platforms and data sources.

<Card
title="Crawling Manager API"
icon="robot"
href="/system-overview/crawling-manager"
>
Complete guide to scheduling and managing automated data crawling jobs across Gmail, Google Drive, OneDrive, SharePoint, Confluence, and Slack. Includes flexible scheduling options (hourly, daily, weekly, monthly, custom cron), job lifecycle management (pause, resume, remove), queue monitoring, and real-time job status tracking with comprehensive statistics and error handling.
</Card>

### Mail Service
<Card title="Mail Service API" icon="envelope" href="/system-overview/mail-service" >
Internal reference for template-based system email, SMTP configuration, attachments, CC recipients, scoped authentication, and send-attempt metadata. The reviewed mail route has no BCC field or inbox-delivery tracking; confirm the deployed Enterprise API before integrating with it.
</Card>
