Novaplan AI is a closed-source product. Novaplan creates your workspace and invites users; customer access does not require a source-code checkout or a local platform installation.

Before building an integration, confirm with Novaplan which developer features and permissions are available in your workspace.

## Integration reference

- [OAuth 2.0 applications](/developer/oauth2): application authorization and user sign-in.
- [Personal access tokens](/developer/personal-access-tokens): authentication for tools acting on behalf of a user.
- [API reference](/developer/api-reference): the available documentation for service APIs.
- [MCP overview](/mcp/overview): connecting compatible clients to a workspace.

Use the workspace address supplied by Novaplan. Keep API paths, scopes, and configuration identifiers exactly as documented; some underlying identifiers retain the upstream product name.

## Help with an integration

Contact [Novaplan support](/contact-us) with the workflow you want to support and the applications involved. Do not include credentials or tokens in the request.
