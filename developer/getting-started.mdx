Novaplan AI is a closed-source product. Novaplan creates your workspace and invites users; customer access does not require a source-code checkout or a local platform installation.

Novaplan AI supports the documented developer and integration features. Coordinate setup and the required workspace permissions with the Novaplan team.

## Integration reference

- [OAuth 2.0 applications](/developer/oauth2): application authorization and user sign-in.
- [Developer API access](/developer/api-reference): approved integration paths and how to confirm the REST contract for your workspace.
- [Novaplan Support](/contact-us): approved MCP client and personal access token setup for your workspace.

Use the workspace address supplied by Novaplan. Support will confirm the correct API paths, scopes, and configuration identifiers for your workspace.

## Help with an integration

Contact [Novaplan support](/contact-us) with the workflow you want to support and the applications involved. Do not include credentials or tokens in the request.
